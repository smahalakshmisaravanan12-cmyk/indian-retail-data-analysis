 Project Overview
The Indian Retail Data Analysis project focuses on analyzing retail sales data using Microsoft Excel. The main goal is to understand sales performance, identify customer segments, and discover useful business insights from the data.

 Project Objectives
- Analyze retail sales data.
- Understand sales performance and trends.
- Segment customers using RFM Analysis.
- Create charts and visualizations to present insights.
- Support better business decision-making through data analysis.

Tools and Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts and Data Visualization
- RFM Analysis

 Project Work
- Organized and cleaned the retail dataset.
- Analyzed sales data using Excel.
- Created Pivot Tables to summarize information.
- Performed RFM Analysis to categorize customers.
- Identified customer segments such as Champions, Loyal, Potential Loyalist, At Risk, and Lost.
- Created charts to visualize customer segment distribution and sales trends.

 Key Learnings
- Data cleaning and organization
- Sales data analysis
- Customer segmentation
- Pivot Table analysis
- Data visualization using Excel
This project helped me improve my practical skills in Microsoft Excel and understand how data analysis can be used to identify sales trends and customer behavior.
